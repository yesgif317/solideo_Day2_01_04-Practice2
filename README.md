# 글로벌 여행 플래너 (Global Travel Planner)

국내 및 해외 여행을 위한 맞춤형 여행 계획 웹 애플리케이션

## 프로젝트 개요

이 프로젝트는 사용자가 국내 및 해외 여행을 쉽게 계획할 수 있도록 도와주는 반응형 웹 애플리케이션입니다.
실시간 교통 정보, 개인화된 추천, 구글 지도 연동 등의 기능을 제공합니다.

## 주요 기능

### 1. 여행 경로 계획 시스템
- **출발지/도착지 입력**
  - 건물명 또는 주소 입력 가능
  - 자동완성 기능
  - 최근 검색 기록 표시 (로컬스토리지)
  - 인기 출발지/도착지 프리셋 버튼

- **날짜 및 시간 설정**
  - 캘린더를 통한 날짜 선택
  - 30분 단위 시간 선택
  - 여행 기간 슬라이더 (1-30일)
  - 여행 기간 프리셋 (당일치기, 1박2일, 3박4일, 1주일, 2주)

- **추가 정보**
  - 여행 인원 선택 (1-10명)
  - 예산 범위 설정
    - 국내: 10만원 ~ 500만원
    - 해외: $500 ~ $10,000
  - 자동 여행 타입 감지 (국내/해외)

### 2. 실시간 교통 정보 시각화

#### 국내 교통 수단
- **기차**: KTX, SRT, ITX, 무궁화호
- **버스**: 고속버스, 시외버스
- **항공**: 국내선 항공편
- **자동차**: 렌터카/자가용 예상 정보

#### 해외 교통 수단
- **항공**: 국제선 (직항/경유 구분)
- **기차**: Eurostar, Shinkansen, Amtrak
- **버스**: FlixBus, Greyhound
- **지하철/메트로**: 주요 도시 교통 정보

#### 교통 정보 표시 항목
- 출발/도착 시간
- 소요 시간
- 요금 (좌석 등급별)
- 교통 수단명/회사명
- 필터링 기능 (전체/항공/기차/버스/자동차)

### 3. 지도 및 타임라인 시각화
- **구글 지도 연동**
  - 출발지-도착지 경로 표시
  - 마커 및 경로 시각화

- **타임라인 뷰**
  - 시간별 일정 표시
  - 출발, 이동, 도착 정보
  - 숙소 체크인 정보 (다일 여행 시)

### 4. 개인화 추천 시스템
- **여행지 추천**
  - 인기 관광지
  - 평점 및 리뷰 수
  - 카테고리 태그

- **맛집 추천**
  - 현지 인기 맛집
  - 음식 카테고리
  - 평점 정보

- **숙소 추천**
  - 호텔 및 리조트
  - 위치 정보
  - 편의 시설 태그

### 5. 로컬스토리지 활용
- 최근 검색 기록 저장
- 사용자 설정 저장
- 자동 로드 및 복원

## 설치 및 실행 방법

### 1. 기본 실행
```bash
# 프로젝트 클론 또는 다운로드
git clone <repository-url>

# index.html 파일을 웹 브라우저로 열기
open index.html
```

### 2. 로컬 서버 실행 (권장)
```bash
# Python 3가 설치되어 있는 경우
python -m http.server 8000

# Node.js가 설치되어 있는 경우
npx http-server

# 브라우저에서 http://localhost:8000 접속
```

### 3. Google Maps API 설정 (선택사항)

실제 지도 기능을 사용하려면 Google Maps API 키가 필요합니다:

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성
2. Maps JavaScript API 활성화
3. API 키 생성
4. `index.html` 파일의 다음 부분 수정:
```html
<!-- 변경 전 -->
<script src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&libraries=places"></script>

<!-- 변경 후 -->
<script src="https://maps.googleapis.com/maps/api/js?key=실제_API_키&libraries=places"></script>
```

**참고**: API 키 없이도 애플리케이션의 다른 모든 기능은 정상적으로 작동합니다.

## 사용 방법

### 1. 여행 계획 시작하기

1. **여행 타입 선택**: 국내 여행 또는 해외 여행 선택
2. **출발지 입력**:
   - 직접 입력 또는 자동완성 사용
   - 인기 출발지 프리셋 버튼 클릭
   - 최근 검색 기록에서 선택
3. **도착지 입력**: 출발지와 동일한 방식으로 입력
4. **날짜 및 시간 설정**:
   - 캘린더에서 출발 날짜 선택
   - 드롭다운에서 출발 시간 선택
   - 여행 기간 슬라이더 조정 또는 프리셋 선택
5. **추가 정보 입력**:
   - +/- 버튼으로 여행 인원 조정
   - 슬라이더 또는 직접 입력으로 예산 설정
6. **"여행 계획 시작하기"** 버튼 클릭

### 2. 교통 수단 선택

- 검색 결과에서 다양한 교통 수단 옵션 확인
- 필터 버튼으로 원하는 교통 수단만 표시
- 카드 클릭으로 교통 수단 선택
- 선택된 교통 수단의 상세 타임라인 확인

### 3. 지도 및 경로 확인

- "지도" 탭에서 출발지-도착지 경로 확인
- "타임라인" 탭에서 시간별 일정 확인

### 4. 추천 확인

- 여행지, 맛집, 숙소 탭 전환
- 평점과 리뷰를 참고하여 선택
- 카테고리 태그로 유형 확인

### 5. 내 여행 계획 관리

- "내 여행" 탭에서 저장된 여행 계획 확인
- 과거 검색 기록 자동 저장

## 기능 상세 설명

### 자동완성 기능
- 2글자 이상 입력 시 활성화
- 대소문자 구분 없이 검색
- 최대 8개 제안 표시
- 키보드 탐색 지원 (향후 추가 가능)

### 최근 검색 기록
- 최대 5개 저장
- 중복 제거
- 최신 검색이 상단에 표시
- 로컬스토리지에 영구 저장

### 교통 정보 생성 알고리즘
- 실제 API 대신 시뮬레이션 데이터 사용
- 출발 시간 기준 30분 간격으로 옵션 생성
- 교통 수단별 합리적인 소요 시간 및 가격 생성
- 좌석 등급별 가격 차등 적용

### 추천 시스템
- 국내/해외 구분된 추천 데이터
- 평점 시각화 (별점)
- 리뷰 수 표시
- 카테고리 태그 시스템
